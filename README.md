## What I'm building

I'm currently exploring the agentic AI world: systems where LLMs do more than answer questions, and instead reason through workflows, use tools, interact with data, and operate inside real constraints.

My current open-source focus is **Eunomia**, a governance-first natural-language query middleware for LLM-driven analytics.

### Eunomia

Eunomia is built around a simple belief:

> LLMs can generate SQL, but they should never be trusted to authorize access to data.

It sits between an LLM and a data warehouse, enforcing identity, catalog authorization, SQL validation, PII masking, and audit trails in code.

- **Identity:** Keycloak OIDC / JWT validation
- **Authorization:** OpenMetadata tag policies
- **Retrieval:** Qdrant-backed catalog-aware RAG
- **SQL safety:** `sqlglot` AST validation before execution
- **Privacy:** role-aware PII masking
- **Audit:** request-level traceability for governed analytics
